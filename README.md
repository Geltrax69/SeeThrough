# SeeThrough

Quick Look, but for the things Quick Look is bad at.

Hit a global hotkey and the current Finder selection previews in a floating
panel — long videos with real scrubbing, zip contents without unzipping, and
folders showing what's actually inside them.

macOS won't let anything replace Finder's spacebar, so SeeThrough uses its own
hotkey instead.

## Build

```bash
./build.sh && open SeeThrough.app
```
